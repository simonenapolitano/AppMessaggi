# :computer: FUNZIONAMENTO APP :computer:

- L'app ha un GUI molto semplice e intuitiva.
- La GUI presenta pulsanti con scritto all'interno la funziona che si andrà a svolgere.
- Per far funzionare l'app bisogna avviare prima il server.
- Per poter connettersi ad altri PC che non sono sconnessi alla stessa rete utilizzare app che simulano una connessione LAN (es. [Radmin VPN](https://www.radmin-vpn.com/)).
